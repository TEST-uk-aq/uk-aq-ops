# System documentation drafts

Files under `system_docs/drafts/` are design drafts only.

They are not active system contracts, are not part of the required reading order, and must not be used by Codex or another coding agent to constrain or change current implementation unless the user explicitly asks to promote and implement a named draft.

A draft becomes authoritative only when ChatGPT in Chat mode deliberately moves its agreed behaviour into the relevant active `system_docs/<area>/` contract and updates the active indexes.

Drafts may describe future architecture, names, queues, schemas or workflows that do not yet exist. Current code and active contracts continue to govern until that promotion occurs.
