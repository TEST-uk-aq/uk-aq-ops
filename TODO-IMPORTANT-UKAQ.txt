## 2. Configuration file to amend

Amend:

```text
config/uk_aq_github_env_targets.csv
```

Remove only rows matching these prefixes:

```text
GCP_BLONDON_NODES_SCHEDULER_
GCP_BLONDON_COMMUNITIES_SCHEDULER_
GCP_SOS_SCHEDULER_
GCP_OPENAQ_SCHEDULER_
```

An efficient local command would be:

```bash
python3 - <<'PY'
from pathlib import Path

path = Path("config/uk_aq_github_env_targets.csv")
prefixes = (
    "GCP_BLONDON_NODES_SCHEDULER_",
    "GCP_BLONDON_COMMUNITIES_SCHEDULER_",
    "GCP_SOS_SCHEDULER_",
    "GCP_OPENAQ_SCHEDULER_",
)

lines = path.read_text(encoding="utf-8").splitlines()
kept = [
    line for line in lines
    if not any(line.startswith(prefix) for prefix in prefixes)
]
path.write_text("\n".join(kept) + "\n", encoding="utf-8")
PY
```

Do not broadly remove all `GCP_*_SCHEDULER_*` rows because the same file also contains unrelated maintenance and operational services.

No change is needed to:

```text
scripts/uk_aq_sync_github_secrets.sh
```

It reads the target CSV generically and does not hardcode the connector scheduler variables.

## Connector ingest scheduler ownership

For TEST Cloud Run connector-ingest services, recurring external dispatch is

## Do not delete

Keep all of these:

* the five Cloud Run services;
* their runtime service accounts;
* `GCP_OPENAQ_TASK_QUEUE_ID` and the OpenAQ Cloud Tasks queue;
* `GCP_OPENAQ_TASK_INVOKER_SERVICE_ACCOUNT`;
* `SCHEDULER_D1_JOB_KEY` in each workflow;
* all five Cloudflare D1 jobs;
* `CLOUDFLARE_ACCOUNT_ID`;
* `CLOUDFLARE_API_TOKEN`;
* `UK_AQ_EDGE_UPSTREAM_SECRET`;
* `scripts/cloudflare/uk_aq_reconcile_ingest_scheduler_url.sh`;
* Pub/Sub topics and publisher permissions;
* Artifact Registry and Secret Manager resources;
* `scheduler_backend='google_cloud_run'` in the connectors table.

Do not delete service accounts merely because they were used by GCP Scheduler. The workflows normally fall back to the Cloud Run runtime account, and OpenAQ may also have reused its scheduler account for Cloud Tasks.
