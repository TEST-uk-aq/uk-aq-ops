# UK AQ ingestion architecture review

**Keep GCP primary while measuring the 30-minute change. If TEST billing shows a material avoidable connector cost, pilot MacBook-first ingestion for SAQN using Cloudflare-controlled failover with a durable completion receipt.** The canonical connector code is portable. The missing pieces are an unattended Mac identity, a way to prove that a specific scheduled run completed its writes and Pub/Sub publication, and a safe handover when the Mac stops responding.

The existing D1 scheduler and connector claims are useful foundations. They cannot safely implement staggered failover as they stand. In particular, a connector can record a recent start and then fail, causing the next scheduled GCP invocation to skip. A reported success can also coexist with missing Pub/Sub messages. Both cases matter because Latest Snapshot and ObsAQIDB depend on publication.

## Failover and authentication

**B1 is unsafe as proposed.** The D1 dispatch claim deduplicates a scheduler slot. The IngestDB connector claim is a separate, time-limited overlap guard. It accepts a caller-supplied start timestamp and has neither a renewable owner token nor fencing. The official-network runner illustrates the failure mode: it anchors the scheduled due check on `last_run_start`, even after failure, and its completion update filters only by connector ID. A staggered GCP safety call can therefore skip a failed Mac attempt as `not_due` or `in_flight`. If takeover occurs after expiry, a delayed Mac process can still write data or overwrite run state. A `200`, a recent checkpoint or `claim_not_acquired` provides insufficient evidence to suppress fallback. [Official-network due check and completion update](https://github.com/TEST-uk-aq/uk-aq-ingest/blob/ff9cf85/workers/uk_aq_official_network_cloud_run/run_job.py#L79-L173) · [Claim RPC](https://github.com/TEST-uk-aq/uk-aq-schema/blob/9c6b132/schemas/ingest_db/uk_aq_rpc.sql#L1476-L1527)

**B2 can start small.** Reuse the existing D1 scheduler, slot key and deployment-managed GCP URL. Have the Mac pull assigned work over an authenticated outbound connection. Use a durable attempt ID and ownership generation, one authoritative executor at a time per connector, and explicit deadlines. A receipt must identify the slot and active attempt and show completion of required primary writes, checkpoint/result handling and all required Pub/Sub batches, or an explicit valid no-work reason. Pub/Sub acceptance closes the publisher’s responsibility for the run. Subscriber delivery and public freshness are separate acceptance signals. The Worker can check the outcome on later ticks and conditionally assign GCP to the **same** slot. Its retry must resume or replay that slot through the canonical runner even when the ordinary interval would suppress a fresh scheduled run. Bound retries and retain a terminal failure for alerting. [D1 dispatch storage](https://github.com/TEST-uk-aq/uk-aq-ingest/blob/ff9cf85/cloudflare/scheduler/worker.mjs#L513-L539) · [Pub/Sub batch response](https://github.com/TEST-uk-aq/uk-aq-ingest/blob/ff9cf85/supabase/functions/_shared/observs_client.ts#L395-L445)

The simplest existing reconciliation pattern is Nodes. After a 90-second response wait, D1 can check `/status` at approximately 5, 10 and 14 minutes. It correlates the latest connector run by a start-time window and can finish as `unconfirmed`. Reuse staged reconciliation and the run-result fields, replacing approximate correlation with an exact attempt ID. The MacBook watchdog supplies a different function. It calls each scheduler’s `/run-if-due` after the minute boundary, and D1 determines whether Cron or the watchdog claimed the tick. Reuse its launchd packaging, bounded local logs and shutdown conventions, with separate credentials and health reporting for the executor. A Mac outage takes out both local processes, so automatic GCP fallback depends on Cloudflare and D1 being available. [Nodes reconciliation](https://github.com/TEST-uk-aq/uk-aq-ingest/blob/ff9cf85/cloudflare/scheduler/worker.mjs#L873-L1025) · [Watchdog operation](https://github.com/TEST-uk-aq/uk-aq-ops/blob/cc617456/scripts/mbpro_scheduler_watchdog/README.md#L12-L31)

For crash safety, a lease must govern more than the receipt. On expiry or loss of renewal, the old executor must stop entering write stages, and a resumed process must reacquire work before proceeding. Fence run and checkpoint mutations at the shared write boundary. For Pub/Sub, a lease check cannot recall an in-flight HTTP request. A crash can also occur after a DB commit or after Pub/Sub accepts a batch but before the receipt is stored. The pilot therefore needs a durable, bounded replay of the same work or payload, with a defined policy for ambiguous publication and same-timestamp corrections. Existing upserts and consumer deduplication help with identical replay, but two executors publishing different values for the same timestamp can change the outcome. If a candidate cannot establish safe replay within its source window and freshness budget, keep that connector on GCP. Classify source partials, runtime exhaustion, secondary-delivery failure and valid no-work separately so that a provider outage does not trigger a rapid duplicate poll. [IngestDB observation key](https://github.com/TEST-uk-aq/uk-aq-schema/blob/9c6b132/schemas/ingest_db/uk_aq_core_schema.sql#L1186-L1195) · [Latest Snapshot replacement policy](https://github.com/TEST-uk-aq/uk-aq-system-docs/blob/03fa115/system_docs/latest_snapshot/contract.md#L94-L110)

**All current connector Pub/Sub publisher implementations need an authentication change.** Communities, SOS and OpenAQ share the Deno metadata-server publisher. Nodes and the WAQN/SAQN/NI family each have a Python metadata-server publisher, and Sensor.Community has its own Node version. OpenAQ also calls the metadata server for its Cloud Tasks control path. Use Google Application Default Credentials through a compatible library or token provider in the same code on both hosts. Cloud Run can retain its attached identity. For unattended Mac execution, use Workload Identity Federation backed by an approved renewable machine identity, optionally impersonating a dedicated publisher service account. Scope publishing to the TEST topic. A supervised impersonated ADC login can establish feasibility, but unattended renewal through reboot and logout is a pilot dependency. Keep the publisher separate from billing, deployment, subscription and Cloud Tasks identities. The Mac’s Supabase authorisation is a separate gate. The existing shared pooled role is contracted for authorised Cloud Run calls, and current connector bookkeeping includes service-role access. Agree the narrow Mac grant and control interface before moving either capability. [Deno publisher](https://github.com/TEST-uk-aq/uk-aq-ingest/blob/ff9cf85/supabase/functions/_shared/observs_client.ts#L368-L392) · [Nodes publisher](https://github.com/TEST-uk-aq/uk-aq-ingest/blob/ff9cf85/scripts/blondon_nodes/blondon_nodes_ingest.py#L225-L266) · [Official-networks publisher](https://github.com/TEST-uk-aq/uk-aq-ingest/blob/ff9cf85/scripts/official_networks/official_network_ingest.py#L266-L334) · [Sensor.Community publisher](https://github.com/TEST-uk-aq/uk-aq-ingest/blob/ff9cf85/workers/uk_aq_sensorcommunity_cloud_run/index.mjs#L424-L498) · [OpenAQ task credential](https://github.com/TEST-uk-aq/uk-aq-ingest/blob/ff9cf85/workers/uk_aq_openaq_cloud_run/run_job.ts#L1276-L1295) · [Google ADC](https://cloud.google.com/docs/authentication/application-default-credentials) · [Google Workload Identity Federation](https://cloud.google.com/iam/docs/workload-identity-federation)

**Rank for the initial decision:** A first, then a one-connector B2 pilot if the cost evidence warrants it. Within the pilot, prefer SAQN, then WAQN or NI according to current source health and attributed cost. **Long term:** expand B2 selectively under C where each connector earns its operating cost. Keep OpenAQ and the two subscribers in GCP initially. A simpler alternative is to suppress demonstrably redundant GCP starts using a reliable due signal while keeping one executor. Trial that under A only where avoiding a start preserves connector selection, cadence and recovery.

## Cost evidence needed for a financial decision
