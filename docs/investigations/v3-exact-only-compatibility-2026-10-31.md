## Format and metadata details

Schema 2 uses exactly the accepted `_v2` payload kinds and `exact-timeseries-leaf-v2`. The selector remains the existing scope `manifest.json`. Its leaves use `_exact_v2/timeseries_id=<nine-digit-id>/revision=<sha256>.json`; validators recompute that digest from the full canonical semantic leaf with `key` omitted. The selector still pins the actual full leaf body size/SHA. Unknown combinations, noncanonical schema-2 bytes (including duplicate JSON fields), extra proof fields, aligned links, wrong roots, contradictory membership and malformed ranges fail closed. Selected physical schema 3/4 is validated independently of exact-index schema and the explicitly recorded observation hash version.

Reader configuration gains the private code interface `supportedExactSchemas`; it defaults to `[1]`, so existing unconverted consumers do not silently admit schema 2. The normal observations API explicitly supplies `[1, 2]`. This is not an environment selector and cannot activate production. The selected scoped manifest determines the format, never a 404 or another error.

All-schema-1 compact latest retains its original bytes and fields. When schema-2 scopes are represented, each schema-2 root descriptor additionally pins `exact_index_schema_version`, `exact_index_kind` and `exact_leaf_index_version`, alongside its existing selector key/size/SHA. The compact payload carries the deterministic `exact_index_formats` list instead of falsely labelling a mixed registry globally `exact-timeseries-leaf-v1`, and advertises the revision-qualified key template. Existing schema-1 roots retain their original implicit schema-1 representation. Consumers that still demand the old global v1 field must be coordinated before any new-format registry is published. Latest remains operational metadata, not the reader's per-request selector or proof of publication completion.

Cursor 4 is issued only when discovery includes a schema-2 scope. It carries each scope's supported exact-format tuple, physical identity, exact selector key/size/SHA, pinned next leaf and file/group/row coordinates. It has a five-minute private lifetime, preserved across continuations, plus the existing 12,288-character ceiling. The lifetime is a fixed implementation bound, not a new environment variable or a change to cursor 3. Continuations authenticate the current selector identities and pinned immutable leaf, reject expired or stale/substituted state, then decode only the selected segment. No browser cursor or signing/configuration service is added. Existing upstream authentication remains required and cursors are validated as untrusted input.

## Preserved guarantees and cost boundary

- Logical v2 semantics, selected v3 generation, supported physical schema/writer identities, `timeseries-aligned-v2`, decode profile, observation hash semantics and source/status authority remain separate.
- Schema-1 aligned parent/child validation, Node builders, shared canonical publication, Prune original gates, Integrity/SOS-light authority and JSONgen proof requirements remain present. This PR does not make those consumers schema-2-ready.
- The reader retains non-empty requests of at most 24 hours, one segment/1,024 rows per invocation, four discovery index objects/8 MiB, two range reads/8 MiB, strict file SHA/size/required current ETag and conditional ranges. The aggregate discovery byte cap is enforced before each read. No footer discovery, whole-file chart decode or canonical-root walk is added.
- Station History's 16-page/5,000-accepted-R2-row budgets, continuity, chronological settlement, previous-23-hour PM context, R2/recent precedence and DAQI/EAQI behavior are untouched.
- Cache selection reads at most the one or two current scoped manifests before a cache lookup. On a cold miss, request-local reuse avoids fetching them twice; no persistent identity cache is introduced. Cache hits now incur these bounded selector reads and hashes, which are needed to prevent URL-only stale reuse after a format switch. Real TEST CPU and Class B cost must be measured before acceptance.
- Schema-1 continuations still read their deterministic leaf directly. Cursor-4 continuations read at most two pinned scoped selectors plus the current immutable leaf, within the existing four-object budget; they do not rediscover/sort the whole remaining logical range. This additional identity work has not been operationally benchmarked.
