1. Find
Gets source files/data, and compares against Dropbox. Only needs to check if the observs are different. Can use the observations_content hash for this. 
Records the day/connector/pollutant that is incorrect. Can also record both hashes. Debug mode should also record correct hashes.

The dcp_key is put in a queue called queue_find. Status of Hash_mismatch.

2. Build_DCP3
This module looks at the queue_find.
It takes a dcp_key and builds a new version of the parquet files and manifest for the dcp_key.
It removes it from queue_find, and puts it into queue_dcp3 with the status of rebuilt.

This is all this module does. It doesn't add them to a temp_overlay. It just has a temporary store of rebuilt dcp_keys. Parquet and manifests.


3. Build_DC2
This module looks at queue_dcp3. 
It doesn't do anything until all the dpc_keys for an individual dc_key exist in the queue_dcp3.
Then it removes them from the queue, builds the manifest for the dc_key, and puts the manifest in the temp store.
It then adds the dc_key to a queue_dc2.

This module will only build complete manifests for dc_keys, when they all exist in the queue.
